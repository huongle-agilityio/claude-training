# Day 14 — Manual regression checklist

Source: `docs/tickets/test-matrix.md` (Type = manual rows for T1 and T2; T3 rows skipped) plus a smoke check of the features that existed before the click goal.

Setup: `npm run dev`, open the URL Vite prints. Start each row from a fresh page load unless the steps say otherwise.
Theme follows the OS / browser setting (`prefers-color-scheme`); there is no in-app toggle. Switch it with DevTools → Rendering → "Emulate CSS media feature prefers-color-scheme".
375 px = DevTools device toolbar, Responsive, width 375.

Result: write Pass / Fail (plus a note or bug link on Fail).

Run 2026-11-02: every row checked automatically with Playwright 1.64.1 (Chromium) against `npm run dev`; themes via `colorScheme`, 375 px via viewport. Result: 17 Pass, 1 Fail (SM-12). "Readable" in SM-12/SM-13 was measured as text contrast ≥ 4.5:1 against the rendered background.
