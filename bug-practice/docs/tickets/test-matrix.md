# Test matrix — Click goal (T1–T3)

Source: docs/day12/tickets/T1.md, T2.md, T3.md (updated after QA round, 2026-10-29).
Drafted by QA from the tickets only; blocked rows resolved by BA decisions.

Conventions: "goal panel" = the area with the goal input, the progress display and the
congratulation. "Message" = "Goal reached!" with a check icon, under the progress bar.
"Fill" = aria-valuenow / aria-valuemax on the role="progressbar" element (T2 AC9).
